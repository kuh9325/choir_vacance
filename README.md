# GAME SCORE

2026년 9월 5일 초등학교 고학년 실내 게임 행사를 위한 실시간 점수 입력·전시 웹앱입니다.

## 주요 화면

- `/admin` — 운영자 점수 입력 및 행사 제어 (초기 PIN: `0912`)
- `/display` — 프로젝터/TV 점수 전광판
- `/results` — 순위 단계 공개 및 시상 화면
- `/admin/charades` — 몸으로 말해요 진행자 화면
- `/display/charades` — 몸으로 말해요 프로젝터 전광판
- `/admin/telestration` — 텔레스트레이션 진행 + 통합 점수 입력 화면
- `/display/telestration` — 텔레스트레이션 프로젝터 전광판

## 몸으로 말해요 LIVE

몸으로 말해요는 종합점수에 포함되지 않는 10분 워밍업입니다.

- 동물 / 직업 / 음식 / 스포츠 / 행동 / 교통수단 / 속담 7개 주제, 총 210개 제시어 내장
- 팀 수와 팀별 인원에 따라 라운드 수와 턴 시간을 자동 계산
- 기본 5팀 × 4명 × 10분에서는 팀당 2회, 총 10턴으로 배정
- 관리자에서 제시어 뽑기/공개/가리기/다음 제시어/타이머 시작·일시정지·재개/다음 팀 제어
- 전광판에 팀·주제·제시어·담당 인원·턴 타이머·전체 타이머 표시
- 팀 교대 시 제시어 자동 숨김
- 같은 세션에서는 가능한 한 같은 제시어가 반복되지 않음
- 기존 점수 상태와 저장 레코드를 분리하여 점수판을 덮어쓰지 않음

## 텔레스트레이션 LIVE

- 확정 제시어 20개: 4라운드 × 5팀
- 역할 순환: 1R 1→2→3→4 / 2R 2→3→4→1 / 3R 3→4→1→2 / 4R 4→1→2→3
- 진행: 제시어 확인 → 첫 그림 → 첫 추측 → 두 번째 그림 → 최종 정답 → 판정
- 기본 시간: 그림 35초 / 추측 20초 / 그림 35초 / 최종 정답 20초
- 관리자 화면에서만 팀별 제시어를 개별 공개
- 전광판에는 현재 단계·담당 번호·대형 타이머를 표시하고 제시어는 노출하지 않음
- `/admin/telestration` 오른쪽 아래의 `점수 입력` 버튼으로 같은 화면에서 5개 팀 R1~R4 O/X를 즉시 수정 가능
- 정답은 라운드당 +5점이며 기존 `teleRounds`에 직접 반영되어 종합 70점 점수판과 즉시 연동
- 텔레스트레이션 진행 상태는 D1 `event_state` id=3, 실제 점수는 기존 점수판 id=1에 저장

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 빌드

```bash
npm run build
```

## 데이터와 오프라인 동작

- 점수판: Cloudflare D1 `event_state` id=1
- 몸으로 말해요 진행상태: id=2
- 텔레스트레이션 진행상태: id=3
- 모든 변경은 같은 기기의 `localStorage`에도 백업
- 같은 브라우저 탭은 `BroadcastChannel`로 즉시 갱신
- 다른 기기는 서버 상태를 주기적으로 가져옴

## Cloudflare 배포

독립 Cloudflare Workers 배포 설정은 `wrangler.jsonc`에 있습니다. 연결된 D1 데이터베이스의 바인딩 이름은 `DB`입니다.

```bash
npm run deploy
```

GitHub 기반 Cloudflare Workers Builds에서는 빌드 명령을 `npm run build`, 배포 명령을 `npx wrangler deploy`로 설정합니다.

## 점수 규칙

- 몸으로 말해요: 무배점 워밍업
- 텔레스트레이션: 성공 라운드당 5점, 20점 만점
- 바닥팩맨: 일반 먹이 1점, 황금 먹이 5점, 20점 만점
- 팀전 보물찾기: 발견 1점 + 정답 3점 + 미션 2점 − 힌트 1점, 30점 만점
- 종합 동점: 보물찾기 → 텔레스트레이션 → 보물찾기 완주시간 순
- 위 조건까지 같으면 공동순위
