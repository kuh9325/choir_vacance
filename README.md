# GAME SCORE

2026년 9월 5일 초등학교 고학년 실내 게임 행사를 위한 실시간 점수 입력·전시 웹앱입니다.

## 주요 화면

- `/admin` — 운영자 점수 입력 및 행사 제어 (초기 PIN: `0912`)
- `/display` — 프로젝터/TV 점수 전광판
- `/results` — 순위 단계 공개 및 시상 화면
- `/admin/charades` — 몸으로 말해요 진행자 화면
- `/display/charades` — 몸으로 말해요 프로젝터 전광판
- `/admin/telestration` — 텔레스트레이션 진행·정답 판정 화면
- `/display/telestration` — 텔레스트레이션 프로젝터 전광판

## 몸으로 말해요 LIVE

몸으로 말해요는 종합점수에 포함되지 않는 10분 워밍업입니다.

- 동물 / 직업 / 음식 / 스포츠 / 행동 / 교통수단 / 속담 7개 주제, 총 210개 제시어 내장
- 팀 수와 팀별 인원에 따라 라운드 수와 턴 시간을 자동 계산
- 기본 5팀 × 4명 × 10분에서는 팀당 2회, 총 10턴으로 배정
- 관리자에서 제시어 뽑기/공개/가리기/다음 제시어/타이머 시작·일시정지·재개/다음 팀 제어
- 전광판에 팀·주제·제시어·담당 인원·턴 타이머·전체 타이머 표시
- 팀 교대 시 제시어 자동 숨김
- 같은 세션에서는 가능한 한 같은 제시어가 반복되지 않음
- 기존 점수 상태와 저장 레코드를 분리하여 점수판을 덮어쓰지 않음

## 텔레스트레이션 LIVE

텔레스트레이션은 5개 팀이 동시에 진행하는 4라운드 게임이며, 라운드 성공마다 기존 점수판에 5점씩 반영되어 20점 만점입니다.

- 확정 제시어 20개: 4라운드 × 5팀, 라운드가 올라갈수록 쉬운 명사 → 상태 표현 → 행동 → 재미있는 복합 장면 순으로 난이도 상승
- 진행자 화면에서만 팀별 제시어를 개별 공개하여 전광판으로 답이 유출되지 않음
- 전광판에는 현재 라운드, 단계, 담당 학생 번호, 대형 타이머, 전체 15분 타이머 표시
- 역할 자동 순환: 1R `1→2→3→4`, 2R `2→3→4→1`, 3R `3→4→1→2`, 4R `4→1→2→3`
- 기본 단계 시간: 첫 그림 35초 → 추측 20초 → 두 번째 그림 35초 → 최종 정답 20초
- 정답 확인 단계에서 팀별 `정답 +5점`을 누르면 기존 `teleRounds`에 즉시 반영
- 의미가 같은 표현은 진행자가 인정 가능하며 관리자 화면에 인정 예시 표시

## 데이터와 오프라인 동작

### 점수판

- Cloudflare D1의 `event_state` id=1 레코드가 서버 원본 데이터입니다.
- 모든 변경은 같은 기기의 `localStorage`에도 즉시 백업됩니다.
- 같은 브라우저의 운영자/전광판 탭은 `BroadcastChannel`로 즉시 갱신됩니다.
- 다른 기기는 서버 상태를 0.8초 간격으로 가져옵니다.
- 네트워크가 끊기면 로컬 입력을 계속 받고, 연결 복구 시 자동 업로드합니다.

### 몸으로 말해요

- 같은 `event_state` 테이블의 id=2 레코드에 독립적으로 저장합니다.
- 점수판과 저장 레코드가 분리되어 서로 덮어쓰지 않습니다.
- localStorage 키와 BroadcastChannel도 별도로 사용합니다.

### 텔레스트레이션

- 라이브 진행 상태는 같은 `event_state` 테이블의 id=3 레코드에 독립 저장합니다.
- 실제 텔레스트레이션 득점은 id=1의 기존 점수판 `teleRounds`를 갱신합니다.
- 진행 상태 초기화와 점수 기록을 분리하여 현장 진행 중 실수로 점수가 사라지는 것을 방지합니다.

## Cloudflare 배포

독립 Cloudflare Workers 배포 설정은 `wrangler.jsonc`에 있습니다. 연결된 D1 데이터베이스의 바인딩 이름은 `DB`입니다.

```bash
npm run deploy
```

GitHub 기반 Cloudflare Workers Builds에서는 빌드 명령을 `npm run build`, 배포 명령을 `npx wrangler deploy`로 설정합니다. 새 D1 데이터베이스를 사용할 때는 `drizzle/0000_lethal_black_crow.sql`을 먼저 적용해야 합니다.

## 현장 운영 권장사항

행사 전 운영자 휴대폰과 프로젝터 기기에서 URL을 한 번씩 열어 두고, 전광판을 전체화면으로 전환해 주세요. 몸으로 말해요는 연기하는 학생이 화면을 볼 수 있고 맞히는 학생은 화면을 등지도록 배치합니다. 텔레스트레이션은 각 라운드의 첫 그림 담당만 진행자 휴대폰에서 자기 팀 제시어를 확인한 뒤 시작합니다.
