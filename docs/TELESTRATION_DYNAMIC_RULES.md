# 텔레스트레이션 동적 진행 규칙

- 종합점수 규칙 보호를 위해 **4개 채점 라운드 × 5점 = 20점**은 고정한다.
- 팀 수는 3~8팀을 지원하며 모든 팀은 동시에 진행한다.
- 팀별 인원수는 기본 4명, 2~8명을 정식 지원한다. 1명으로 설정되어도 앱은 중단되지 않고 같은 학생을 반복 배정한다.
- 각 라운드의 시작 담당은 라운드마다 한 명씩 순환한다.
- 라운드 안의 전달 체인은 최대 팀 인원수에 맞춰 자동 생성한다.
  - 홀수 인원일 때는 마지막 결과가 반드시 단어가 되도록 추측 단계를 하나 더 붙인다.
  - 예: 최대 3명 → 4단계, 4명 → 4단계, 5명 → 6단계, 6명 → 6단계, 7명 → 8단계, 8명 → 8단계.
- 인원이 적은 팀은 자기 팀 인원 범위 안에서 담당 번호가 순환한다.
- 총 진행시간은 기본 15분이며, 팀 수가 많아질수록 제시어 공개/판정 여유시간을 더 확보하고, 전달 단계가 많아질수록 단계별 그림·추측 시간을 자동으로 줄인다.
- 그림 단계는 추측 단계보다 더 긴 시간을 자동 배정한다.
- 제시어는 라운드별 8개씩 총 32개를 내장해 8팀까지 중복 없이 배정한다.
